## 1. 사전 준비 체크리스트

### D-7 (일주일 전까지)

- [ ] **참가자 모집** — 2인 1팀 × 5~7팀(파일럿 포함). 조건: 동료 개발자, 저자와 이해관계 없음, 두 사람이 서로 아는 사이면 더 좋음(규범 형성 M4 관찰에 유리).
- [ ] **채점자 2인 섭외** — 세션 참관 불필요. 사후에 M1 채점표와 M3 코딩만 독립 수행.
- [ ] **동의서 인쇄** (§8 양식) — 모듈 채택이므로 "일부 설정은 의도적으로 제한된 기능을 사용합니다" 문구가 **반드시** 들어가야 함. 소속 기관에 IRB/윤리 심의가 있으면 이 시점에 문의(모듈 포함 여부를 명시해서).
- [ ] **워크스페이스 리포 준비** — `bench/study/repo-template/`(TaskBook)에서 팀당 새 사본 3벌(과제쌍 1·2·3용) 복사. 사본 만들기 명령과 심어 둔 결함 정답지는 `bench/study/README.md`(진행자 전용 — 참가자에게 노출 금지).
- [ ] **카드·설문 인쇄** — 과제 카드(참가자별 자기 것만!), 정지 탐침 카드 팀당 5장, 설문지 인당 2장(§7).

### D-1 (전날)

- [ ] **장비** — 참가자 노트북 2대(또는 지참 안내), 같은 LAN, 진행자 노트북, 화면+음성 녹화 수단, 타이머.
- [ ] **리허설** — §2의 명령으로 서버를 띄우고: ① 두 브라우저 동시 접속 ② 동시 제출 시 두 스트림이 각자 흐르는지(병렬) ③ 세션 디렉토리에 `turns.jsonl`이 쌓이는지 확인.
- [ ] **파일럿 1팀 일정 확정** — 파일럿에서 점검할 것: 75+8분에 들어가는가, 정지 탐침이 흐름을 지나치게 끊는가, 과제가 20분에 끝나는가(너무 일찍 끝나면 카드에 확장 과제 추가).

## 2. 당일: 서버 기동 (세션 시작 15분 전)

조건마다 서버를 새로 띄운다(계약은 세션 시작 시 고정되므로 조건 전환 = 재기동). 워크스페이스는 **그 조건용 리포 사본** 디렉토리에서 실행.

```bash
# 공통 환경 (키는 커밋 금지 — 당일 셸에서만 export)
export AGENT_CLI_PROVIDER=openai
export AGENT_CLI_BASE_URL=<온프렘 엔드포인트>
export AGENT_CLI_API_KEY=<발급 키>
export AGENT_CLI_MODEL=<모델명>

# 조건 P (병렬) — 스코핑은 기본 켜짐이므로 플래그 불필요
cd <이 조건용 리포 사본>
agent-cli web --host 0.0.0.0 --port 8765 --token team<N>-<조건> --turn-metrics \
  --concurrency-contract parallel

# 조건 S (직렬)
agent-cli web --host 0.0.0.0 --port 8765 --token team<N>-<조건> --turn-metrics \
  --concurrency-contract serial

# 모듈 C (미스코핑 탐지) — 병렬 + 스코핑 명시적 해제
agent-cli web --host 0.0.0.0 --port 8765 --token team<N>-c --turn-metrics \
  --concurrency-contract parallel --no-turn-scoping
```

참가자 접속: 각자 브라우저에서 `http://<진행자IP>:8765/?token=team<N>-<조건>`.

**조건 순서·과제쌍 배정표** (순서·쌍 상쇄, 모듈은 항상 마지막·쌍3):

| 팀 | 조건 A (첫 20분) | 조건 B (다음 20분) | A 과제쌍 | B 과제쌍 |
|---|---|---|---|---|
| 파일럿 | S | P | 쌍1 | 쌍2 |
| 1 | S | P | 쌍1 | 쌍2 |
| 2 | P | S | 쌍2 | 쌍1 |
| 3 | S | P | 쌍2 | 쌍1 |
| 4 | P | S | 쌍1 | 쌍2 |
| 5 | S | P | 쌍1 | 쌍2 |
| 6 | P | S | 쌍2 | 쌍1 |

**세션 보관**: 조건 종료마다 세션 디렉토리(`.agent-cli/` 아래, `turns.jsonl`·`history.jsonl`)를 `study-data/team<N>/<조건>/` 으로 복사.

## 4. 진행자 대본

### 4-1. 도입 (읽기)

> "두 분이 하나의 AI 코딩 에이전트를 함께 씁니다. 같은 대화, 같은 작업 폴더예요. 각자 받으신 카드의 과제를 하시면 되고, 상대와 상의하셔도 되고 안 하셔도 됩니다. 상대의 과제가 무엇인지는 알려드리지 않습니다. 중간에 두 번, 10초짜리 질문 카드를 드릴 겁니다. 저는 관찰만 하고 도와드리지는 않습니다. 시작 신호가 있으면 **두 분 동시에** 첫 지시를 보내 주세요."

### 4-2. 정지 탐침 (카드 내밀며)

> "10초만요. **지금 상대분이 무엇을 하고 있나요?** 카드에 한 줄로 적어 주세요. 모르시겠으면 '모름'이라고 쓰시면 됩니다. 서로 화면은 보지 말아 주세요."

### 4-3. 전환

> "다음은 같은 시스템의 **다른 설정**입니다. 무엇이 다른지는 끝나고 말씀드릴게요. 새 과제 카드를 드립니다."

### 4-4. 관찰 코드 (조건 진행 중 진행자 기록 — 빈도 보고용 아님, 인터뷰 사건 후보용)

`WAIT`(응답만 보며 대기) · `ASK`(상대에게 말 걺) · `SURPRISE`(놀람·혼란 표현) · `CROSS`(상대 산출물 언급/조작) · `ABANDON`(취소·재작성). 시각과 함께 메모.

### 4-5. 디브리핑 (요지)

- 조건 차이 공개: "한 조건은 요청을 한 줄로 세웠고(직렬), 한 조건은 동시에 처리했습니다(병렬)."
- **모듈 C 공개(필수)**: "마지막 8분은 에이전트가 누구의 요청을 수행 중인지 알려주는 안전장치를 의도적으로 끈 상태였습니다. 연구 목적은 사람이 그 상태를 알아차릴 수 있는지였습니다."
- 로그에서 본 사건 중 인터뷰에서 다루지 않은 것이 있으면 알린다. 질문을 받는다.

## 6. 인터뷰 (진행자 시트)

### 6-1. 사건 선정 (0:59, 로그에서 3~5개)

우선순위 순서대로 `study-data/team<N>/*/history.jsonl`·`turns.jsonl` 을 훑는다:

1. **오염**: 한 턴이 상대 과제의 파일을 건드림 — history.jsonl 레코드의 `reply_to`(누구 요청 처리 중)와 `files`(만진 경로)가 어긋나는 행. **모듈 C 로그는 반드시 전수 확인**(M2의 정답지).
2. 가장 긴 대기(직렬 조건 turns.jsonl의 enqueue→dispatch 간격).
3. 인터럽트 발생 지점, 또는 같은 요청 재전송.
4. 압축(compact 이벤트)이 돈 구간.
5. 두 참가자 턴이 가장 크게 겹친 구간.

사건이 하나도 없으면 그것도 기록한다("조사할 사건 미발생").

### 6-2. 질문 (사건별 → 공통)

각 사건에 대해 (시각과 화면 맥락만 제시, **해석은 주지 않는다**):

| # | 질문 | 기록 |
|---|---|---|
| 1 | "이때 이런 일이 있었습니다. 기억나세요?" | **M2: hit / miss** |
| 2 | (기억한다면) "그때 무슨 일이라고 생각하셨어요?" | **M3 귀인: 에이전트/시스템/상대/자기/기타** |
| 3 | "뭔가 하셨나요? 안 했다면 왜요?" | 자유 기록 |
| 4 | (못 알아챘다면) "지금 들으니 어떠세요?" | 자유 기록 |

참가자가 로그에 없는 사건을 보고하면 **false alarm**으로 별도 기록.

공통 질문 (남은 시간에 순서대로):

| # | 질문 | 대상 |
|---|---|---|
| 5 | "상대가 무엇을 하는지 알아야 했던 순간이 있었나요? 어떻게 알아냈어요?" | §7.1 |
| 6 | "상대의 작업을 멈추고 싶었던 적 있어요? 멈췄나요? 안 멈췄다면 왜요? 멈춰도 되는 거라고 생각하셨어요?" | §7.2 |
| 7 | "둘이서 뭔가 정한 게 있나요? 말로 정했나요, 그냥 그렇게 됐나요?" | **M4** |
| 8 | "두 설정에서 기다리는 느낌이 달랐나요? 기다리는 동안 뭘 하셨어요? 상대 때문에 기다린다고 느낀 적 있어요?" | 계약 대조 |
| 9 | "팀에서 이걸 쓰시겠어요? 어떤 일에는 쓰고 어떤 일에는 안 쓰시겠어요? 뭐가 있어야 쓰시겠어요?" | **M5** |
